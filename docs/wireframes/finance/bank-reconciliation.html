Bank reconciliation WS4WS5

A new three-step screen at /accounts/:key/reconcile. It compares one bank account's books with the bank's statement. The server already does the work (import, auto-match, match, book, ignore, report, sign-off); only the screen is new. Needs money:reconcile. All figures are made up.

What changes

  1. Column mapping (new). The parser reads the CSV in the browser, so no file is sent to the server until the person confirms. Banks differ, so every column is mapped by the person. WS5
  2. Remember the setup (new). Stored per account in the browser. A later version could keep it on the server for all devices.
  3. Preview and checks (new). Rows with a bad date or amount are flagged and left out. The server also refuses zero amounts and over-long text.
  4. Result and next step (new). Shows the server's counts (added, duplicates, matched). Files over 1,000 lines go in several requests; the counts are added up.

Rules from the server

  • New lines dated on or before the last sign-off (31 Oct 2026) are refused with a message that names that date.
  • Auto-match pairs a line with the nearest open book entry of the same amount within 3 days.

What changes

  1. Review tabs and the Do column (new). Three actions per line, and Reopen on matched or ignored lines. WS5

Rules from the server

  • Match, Book and Ignore are refused on lines dated on or before the last sign-off.
  • A line already matched or ignored must be reopened first.
  • Ignore needs a note. Book cannot use the bank account itself or another money account as the other side.

What changes

  1. As on and statement balance (new). Both are required. The server refuses a date on or before the last sign-off.
  2. The comparison (new) shows the server's report: books balance, entries not yet on the statement, statement lines not yet booked, and the difference. Reconciled means the difference is zero and no line is unmatched.
  3. Sign off (new). Stores the figures, writes an audit entry, and freezes lines on or before that date. Entries still outstanding in the books may remain.
  4. Past sign-offs (new). Newest first, from the list route.

Known limit

  • Sign-off locks statement lines, but it does not stop a back-dated ledger entry into a signed-off month. Only closing the financial year does. The screen should say so near the Sign off button.
