Behaviour

  • From and To list active accounts only, and cannot be the same account.
  • The "after the transfer" line is calculated in the browser from the balances already loaded; the server decides.
  • If the server refuses with the overdraft message, the reason field appears. Sending a reason repeats the request with overrideReason.
  • If the organisation has set a transfer matrix that forbids the pair, the dialog shows the server's message.
