Trial balance WS7

A new screen at /money/trial-balance. It lists every ledger account with its balance on a chosen date, in a Debit column or a Credit column. The two totals must be equal: that is the proof that the books are in order. Opened from the Trial balance button on the Money page. All figures are made up.

What changes

  1. Whole screen is new. The server can already work out a trial balance for one financial year (LedgerService.trialBalance), but only tests use it: no route and no screen. WS7
  2. Pick a date, not only a year. The existing query adds up one financial year's entries. That is wrong for money, debts and funds, which must carry forward from earlier years. The new query adds everything up to the date for those, and only the current year's entries for income and expenses. WS7
  3. Account name link. Money accounts link to their statement. Other accounts have no statement yet, so they show plain text. 3
  4. Balanced badge. Compares the two totals. The ledger refuses unbalanced entries, so a red "Out of balance" state is a safety net, not an expected case.
  5. Export CSV and Print use the table as shown, for the accountant. 5

Behaviour

  • A balance below zero on a normal-debit account moves to the Credit column (and the reverse), so each row has one number.
  • Entries that were reversed count as they stand: the original and its reversal cancel out.
  • Accounts with no balance are hidden unless the box is ticked.
  • This is a plain list of balances. It is not a balance sheet or an income statement: those need the organisation's accountant to decide how accounts are grouped, and are out of scope.
