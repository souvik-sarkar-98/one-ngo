Account statement WS4WS5

A new screen at /accounts/:key/statement. It lists every entry on one money account between two dates, with a running balance and a link to the record that caused it. Opened from the Statement action on the Money page. All figures are made up.

2,000 lines at most per request. If the range holds more, a "Load more" button appears under the table.

What changes

  1. Whole screen is new. Nothing like it exists today: the server cannot list the lines of one account over a date range, and the Money page shows only a current balance. WS4
  2. Source column. Each line links to the record that caused it (donation, claim, fee, earning). Transfers and manual bank bookings show a badge instead of a link. Reversed entries are struck through and the reversal shows its own line.
  3. Running balance adds each line to the opening balance. The closing balance must equal the account balance on the Money page for the same date.
  4. Export CSV downloads the table as shown, with the same date range.

Behaviour

  • Closed accounts still open the statement.
  • A person who cannot read a record type still sees the line, but the source shows only the record number with no link.
  • The Reconcile button appears only for people with money:reconcile, and only on bank accounts.

2. Statement, mobile

Lines become cards. The running balance is kept on each card so the account can be checked at a glance.
