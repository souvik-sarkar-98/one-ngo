Home screen redesign

Pins already exist, so they stay exactly as they are. The new things are a search bar and task cards: guided, step-by-step forms (for example "Record a donation"). The cards sit under the pins, behind filter pills that narrow them by area. The current record tiles are kept, folded away. The last section says how this maps to the existing definitions.

Can we do this with the existing definitions?

Mostly yes. Home is already a page definition made of widgets, and record forms already support steps. Checked against core/pages.ts, PageDef in the definition types and the list-view create.steps.

PieceTodayWhat it takes
Pinned listsExistOnly the text changes: ui.pins.yours ("Your pin") becomes "Pinned by you" in all six language files. Tests look the text up by key, so they keep working.
Task cardsDefinition onlyA links widget on the Home page, one link per card, each to /records/<type>?create=new. A link can carry its own permission, so people only see cards they can use. An admin sets it up in the Builder page editor.
Steps inside a cardExistMulti-step forms come from create.steps on the list view. A card just opens that form. Define steps there if a record does not have them yet.
Filter pillsSmall UI changeUse one links widget per area (its label is the area name). Home then draws a pill for each and hides the others. No server or definition format change.
Search barSmall UI changeSearches the text of the cards and the record tiles already loaded, in the browser. The Records screen already does the same for its groups.
One task across several recordsNot possibleFor example donor, then donation, then receipt in one flow. Forms can pass a value on in the address (?donor=d7), but nothing runs a chain. This needs new code, so the wireframe leaves it out.

Decisions needed

  • Which tasks first? The six cards are examples. Pick the jobs people repeat most.
  • Heading text. "Pinned lists" with the tag "Pinned by you" is my suggestion. Other options: "Quick lists", "My shortcuts".
  • Same cards for everyone? Cards on the Home page are the same for all roles, hidden by permission. Per-role cards would use the page's audience setting.
