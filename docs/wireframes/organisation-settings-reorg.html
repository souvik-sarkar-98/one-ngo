Organisation settings — regrouped cards

Proposal for /admin/organisation/settings: split the current “Year and limits” card into focused sections. Each section has its own Save (same audit and API as today: save('settings') vs save('mail')). The financial year start stays on this screen; it is not moved to Finance.

StorageQuota, file store connector, and the usage bar together. The bar sits directly under the quota so limit and use read as one topic.
MailUnchanged: connector, from address, and its own Save.
API and data feedsRate limit and browser origins on one card. Two columns on wide screens; one column on a phone.
Books and numberingFinancial year start month only. When fixed, show a fact line instead of a disabled dropdown.
Sign-inNot a card. A footnote: the platform operator sets password, email codes, and SSO.
