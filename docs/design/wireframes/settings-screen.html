Settings

Settings stays its own screen at /settings, opened from the More tile. It holds a read-only profile, language, two-step status, the user guide, and About. The page name follows the language the person chose.

Organisation settings (name, registrations, theme, layout, storage) stay under Administration. Sign out stays on the initials in the app bar.

Profile is read-onlyName, email, organisation and roles come from the signed-in session. An administrator changes them. There is no Edit button, and no phone or emergency-contact fields. The record-based profile is removed.
Roles are chipsEach role is its own chip under the name, the same treatment as before.
Language applies at onceThe sheet lists each language in its own script, with the English name beside it. Choosing one saves it and closes. There is no Save button.
Two-step is a statusOn or Off, plus a sentence about the person’s role. It is not a switch on this screen.
A centred columnThe groups stay in a 640px column, centred in the page frame. Phone and desktop use the same groups.
The page name translatesThe heading, breadcrumb, and browser title use the same Settings string as the rest of the screen.

What changes from the current screen

  • The flat list becomes three groups: Profile, Preferences, and Help.
  • Profile is read-only: name, email, organisation and roles. Roles are chips. There is no Edit button, no phone or emergency contact, and no profile form. The record-based profile is removed.
  • About no longer prints the server name on the row. Version stays on the row. The server sits under “For support” in the About panel.
  • Two-step gains an explanation. The row does not look clickable.
  • Language shows the native name and the English name, so “हिन्दी” is not clipped against the chevron.
  • The heading and breadcrumb use ui.nav.settings, which has a translation in every supported language.

Interaction

  • Back returns to the screen that was open before More. It does not open the More menu.
  • Language and About are addressable: /settings?panel=language and /settings?panel=about. Reload and Back restore them.
  • Opening a panel moves focus to its title. Tab stays inside. Escape closes the panel. Closing returns focus to the row that opened it.
  • Choosing a language saves it and closes the panel. A failure stays in the panel and keeps the previous language selected.
  • User guide navigates to /guide.
  • Profile details come from the signed-in session, so there is no loading or error state on the Profile card.

Layout and touch

  • Phone and desktop share one column. On desktop the column is 640px and centred in the page frame.
  • Rows are at least 48px tall. Back and Close use a 44×44px target. The close glyph can stay 28px inside that target.
  • Phone panels are bottom sheets, at most 92% of the viewport height. Desktop panels are centred, about 440px wide.
  • On and Off use a text pill. The current language shows the word Selected. Colour is not the only signal.
  • Reduced motion: panels appear in place, with no slide.
