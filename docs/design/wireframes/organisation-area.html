Organisation area

Asha opens Administration and works through the organisation itself. Each screen writes one table. Identity is one card: the logo is previewed with the display name, and the names and language sit under that preview. Profile is how to reach the organisation. Registrations are the certificates. Settings holds the financial year, storage and the API limit.

IdentityOne card. The preview shows the logo beside the display name, as on the app bar and the sign-in page. Replace and Remove save the logo immediately. Save writes the display name, legal name and default language to tenant. Code and the sign-in link are read-only.
ProfileContact, address and time zone, saved to organisation_profile. The logo does not appear here. If the legal name is still empty, a line links to Identity. Confirm identity stays on the setup checklist.
RegistrationsThe list of certificates in organisation_registration. Add, edit and remove stay on this screen. The same type and number cannot be entered twice.
SettingsThree blocks, one Save, all in tenant_setting. The financial-year month is read-only once a year is open or a receipt exists. The storage bar is the sum of files kept. The API limit applies to each API key.
