## After merging into master

1. Run `npm install` in the main checkout: `kysely` is added and `@electric-sql/pglite` removed.
2. Set `DATABASE_URL` in `.env` (for example `postgres://postgres@localhost:5432/ngo`; see `.env.example`). Tests use the derived `ngo_test` database.
3. Restart the dev server with `scripts/dev.ps1`, which starts PostgreSQL if needed and creates and seeds the database.
